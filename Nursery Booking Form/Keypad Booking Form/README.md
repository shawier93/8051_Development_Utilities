# Nursery Booking Form

Collect a booking category and first-class service preference using a keypad and LCD. The program stores the selections in internal RAM.

## Example

Category 2 and service option 1 are stored at addresses 30H and 31H respectively. The service prompt repeats when a value other than 1 or 2 is entered.
